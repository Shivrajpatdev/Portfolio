PROJECT / 01

🌿 Silver Move

Beginner-friendly web project making exercise, mobility, balance and gentle yoga resources more accessible for older adults.

  • Exercise library with filters and sample weekly plans.
  • Gentle yoga guidance, safety information and accessibility-focused design.
  • Responsive, mobile-friendly interface.
  • Built from scratch with HTML5, CSS3 and Vanilla JavaScript.
What I learned: Accessibility is not an afterthought — content structure, readability, navigation and safety information all shape the experience.

🥗 Protein Calculator

Responsive web app that estimates protein content based on food type and serving size.

  • Dynamic calculations for 30+ common foods.
  • Nutrition reference data based on values per 100g.
  • Responsive desktop/mobile interface.
  • Deployed with GitHub Pages.
What I learned: A small JavaScript project can teach the complete front-end loop — data, logic, UI state, responsiveness and deployment.
